# ShopZone E-commerce Prototype

A responsive frontend-only shopping website made with HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is recommended for the remote product photos and Google Fonts.

## Features
- Product catalogue with search, categories and sorting
- Product detail modal
- Wishlist and cart stored in browser LocalStorage
- Quantity controls and item removal
- Checkout form with basic required-field validation
- Demo order confirmation
- Responsive layout

## Important
This is a frontend prototype. It does not have a server, user accounts, inventory management, real order storage, or payment gateway. Checkout only simulates an order in the browser. Product images load from Unsplash; a placeholder is shown if an image cannot load.


## Login page
Open `login.html` to view the responsive sign-in and create-account interface. Authentication is simulated locally for demonstration only; it is not secure production authentication and does not store passwords.
